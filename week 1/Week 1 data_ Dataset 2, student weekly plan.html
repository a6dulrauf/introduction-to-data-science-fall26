Companion table for the grain challenge: one row per student per week. Shares student_id with Dataset 1. Fictional data.

Load it in Google Colab (2 steps)
  1. Press the button below to copy the data.
  2. In a Colab cell, type the first line exactly, paste the data under it, and run the cell:
    %%writefile dataset2.csv
(paste here)
Then check with !head -3 dataset2.csv.
